# Dodge2D

✅ Complete  
❕ Finished Project  

A simple 2D dodge game built in Unity where the player avoids falling objects and survives for as long as possible.

## Gameplay

The objective is simple:

- Move
- Dodge
- Survive
- Try to get the highest score possible

## Controls

- Press A or Left Arrow to move left
- Press D or Right Arrow to move right
- Press Space to restart after game over

## Features

- 2D player movement
- Random falling object spawning
- Collision detection
- Score counter
- Game over screen
- Restart system
- Simple survival gameplay loop

## Additional Feature

For my additional gameplay feature, I added different falling speeds for the falling objects.

Each falling object receives a random speed when it spawns. This makes the game more challenging because some objects fall slowly while others fall faster, making the gameplay less predictable.

## Built With

- Unity
- C#
- Universal Render Pipeline (URP)
- TextMesh Pro

## Important

If you see a TextMesh Pro font import error when opening the project, go to:

Window → TextMeshPro → Import TMP Essential Resources

Unity will automatically re-import the required TMP assets.

After opening the project in Unity, go to:

Assets → Scenes → SampleScene

Press the Play button to run the game.
